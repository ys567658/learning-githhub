# CAN 总线学习笔记（2026-09-30）

## 1. 为什么汽车需要 CAN？
- 汽车内部电子控制单元（ECU）极多，传统点对点连接会导致线束过长、成本过高。
- CAN 总线是一种差分信号总线（CAN_H 和 CAN_L），抗电磁干扰能力极强。
- 它采用广播机制，所有节点共享总线，大幅减少了线束。

## 2. Python 脚本里的字段对应什么？
- `arbitration_id=0x456`：消息的 ID，代表优先级和消息类型（比如车速、转速）。
- `data=[0x00, 0x64]`：8 个字节的数据载荷（0x64 = 100km/h）。
